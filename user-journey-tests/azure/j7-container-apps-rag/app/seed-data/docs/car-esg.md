# Sustainable Leaders Fund

Developed-market equities filtered by an exclusions list and a best-in-class score. Thermal coal, controversial weapons and tobacco are excluded outright; everything else is ranked within its sector and the bottom third dropped.

The fund replaces part of the Global Equity Index holding when a customer opts in to the sustainability preference. It is not an addition — the two are alternatives, and holding both would concentrate the same large-cap names twice. Tracking difference against the unfiltered index has run between minus one and plus two percentage points a year, which customers are told to expect in both directions.

Ongoing charge is 0.28 per cent a year. Distributions are accumulated.
